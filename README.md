# NBTMigrator 🛠️

[English](README_EN.md) | [中文](README.md)

> 用于Minecraft机械动力(Create)模组的NBT蓝图版本迁移工具v1.0
> v1.1版本实现了完整的NBT解析重建，并新增针对嵌套过滤器、剪贴板的支持
> v1.2版本新增**双向转换**支持，可在 1.20.1 ↔ 1.21.1 之间自由转换

## ✨ 特性

- **双向转换**：支持 1.20.1 ↔ 1.21.1 双向迁移
- **自动检测**：智能识别文件版本并自动选择转换方向
- **安全私有**：100%本地运行，不上传任何数据到服务器
- **批量处理**：支持拖拽批量上传NBT文件
- **完整支持**：剪贴板数据、嵌套过滤器全面迁移
- **离线可用**：本地启动index.html，无需网络连接

## 🎯 解决的问题

Minecraft 1.21更新要求NBT数据严格遵循组件化格式，机械动力官方的过滤器内NBT数据迁移异常。本工具可帮助你在不同版本间迁移蓝图数据。

## 🚀 快速使用

### 在线版本
访问 [mc2.top/nbtm](https://mc2.top/nbtm)

### 本地运行
```bash
# 克隆项目
git clone https://github.com/T-splines/NBTMigrator.git

# 直接双击 index.html 文件
ui/index.html
```

## 📋 转换模式

| 模式 | 说明 |
|------|------|
| 🔄 自动检测 | 自动识别版本并反向转换（推荐） |
| ⬆️ 转换到 1.21.1 | 强制转换为 1.21.1 版本 |
| ⬇️ 转换到 1.20.1 | 强制转换为 1.20.1 版本 |

## 🔧 支持的数据迁移

### 剪贴板 (Clipboard)
- 1.20: `Item.tag.Pages[].Entries[]`
- 1.21: `components.create:clipboard_content.pages[][]`

### 过滤器 (Filter)
- 1.20: `tag.Items.Items[]`
- 1.21: `components.create:filter_items[]`
- 支持嵌套过滤器迁移
